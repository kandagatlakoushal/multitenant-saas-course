search_path traps

Your win: given a connection's session state, predict exactly which table an unqualified query reads, or whether it errors.

How lookup works

 search_path = t_acme              SELECT * FROM trades
                                          |
 [pg_temp] -> [pg_catalog] -> [t_acme] -> (nothing else)
  temp tables   system          found
  searched FIRST for tables,
  unless listed explicitly
  • The first schema in the path containing the name wins. Default path: "$user", public.
  • pg_catalog is implicitly first. pg_temp is implicitly first for tables (never for functions).
  • Schemas that don't exist are skipped silently.
  • The current schema is the first existing one. If none exist, CREATE fails.

PostgreSQL: Schemas; Client Connection Defaults.

Four traps

1. A missing tenant schema falls through to public

With search_path = t_newco, public and t_newco not created yet, every query reads public.trades. Rules: set only the tenant schema; keep public empty with no CREATE for the app role (PostgreSQL 15 stopped granting it by default); check that the schema exists against the registry.

2. SET vs SET LOCAL

CommandLasts untilOutside a transaction
SET search_path TO t_acmeEnd of session, so it survives the pool. Reverted if its transaction rolls back.Applies
SET LOCAL ...End of transactionNo effect (warning only)
set_config('search_path', ?, false)Like SET, but takes a bind parameterApplies

PostgreSQL: SET.

3. Temp tables live per connection

Tenant A's CREATE TEMP TABLE is still there when tenant B borrows the connection, and pg_temp is searched first. Use ON COMMIT DROP, or avoid temp tables in shared services.

4. One transaction means one connection, so one path

@Transactional
void nightly() {                       // borrow -> SET search_path TO t_acme
  for (t : tenants) { TenantContext.set(t); repo.save(summary(t)); }   // all into t_acme
}

Rule: one tenant per transaction. Loop outside the transactional method, and call a @Transactional method on another bean (self-invocation bypasses the proxy).
