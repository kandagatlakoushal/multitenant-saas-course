Multi-tenant SaaS for Spring Boot microservices

Convert per-customer services to one shared deployment safely, review code for cross-tenant leaks, and argue the trade-offs. Running example: the trade-processing pipeline (ingester → parser → enricher → rules → reporter, plus the UI gateway).
